<p align="center">
Occlude3d is a shared rendering plugin for Ashita addons. It draws markers, lines, text, and other geometry behind walls and terrain, so they fit into the world instead of appearing through it.
</p>

## ![Install](https://readme-typing-svg.demolab.com/?font=Cinzel&size=25&duration=1&pause=0&color=638EBD&center=false&vCenter=true&repeat=false&width=600&height=42&lines=Install&letterSpacing=0.5px&weight=700)

Developed with **Ashita v4.3.1.2**, plugin interface **4.30**.

1. [Download latest release of Occlude3d](https://github.com/SQLCommit/Occlude3d/releases/latest). Choose the plugin ZIP whose `Interface-N.NN` matches your Ashita plugin interface.
2. Extract into `/ashita/`. The plugin should be at `/ashita/plugins/occlude3d.dll`.
3. In game, run `/load occlude3d`.

**Load automatically:** Add `/load occlude3d` to your startup script in `/ashita/scripts/`.

Tested on Ashita **v4.3.2.1**. Load Occlude3d before addons that use it. The release also includes the `magiccircle` example addon. Occlude3d draws nothing until an addon submits geometry.

## ![Features](https://readme-typing-svg.demolab.com/?font=Cinzel&size=25&duration=1&pause=0&color=638EBD&center=false&vCenter=true&repeat=false&width=600&height=42&lines=Features&letterSpacing=0.5px&weight=700)

| Feature | What it does |
| :--- | :--- |
| **World occlusion** | Hides submitted geometry behind terrain, walls, and world objects. |
| **Drawing primitives** | Lines, ribbons, markers, triangles, sprites, text, bars, rings, decals, and particles. |
| **Shared renderer** | Multiple addons submit through one plugin, with 32 shared owner slots. |
| **Diagnostics** | Inspect active submitters, capacity, dropped submissions, and measured rendering cost. |

## ![Commands](https://readme-typing-svg.demolab.com/?font=Cinzel&size=25&duration=1&pause=0&color=638EBD&center=false&vCenter=true&repeat=false&width=600&height=42&lines=Commands&letterSpacing=0.5px&weight=700)

| Command | Action |
| :--- | :--- |
| `/o3d` or `/o3d ui` | Show or hide diagnostics |
| `/o3d hook` | Toggle the render hook; normally installed automatically on first use |
| `/o3d stats` | Measure the next 60 frames and report to chat and the log |
| `/o3d diag` | Write a full diagnostic report |
| `/o3d legacy on` / `off` | Use the older render-call pattern for comparisons (debug) |

`/occlude3d` also works as the command prefix.

## ![For addon developers](https://readme-typing-svg.demolab.com/?font=Cinzel&size=25&duration=1&pause=0&color=638EBD&center=false&vCenter=true&repeat=false&width=600&height=42&lines=For+addon+developers&letterSpacing=0.5px&weight=700)

Send geometry through `RaiseEvent('occlude3d', ...)`. Check that the plugin is loaded before submitting, use a unique owner ID, and clear your submissions when unloading.

The [API reference](API.md) covers all primitive formats, flags, textures, fonts, limits, and a working Lua example. See [Build instructions](BUILD.md) to compile the plugin.


## ![Logs and support](https://readme-typing-svg.demolab.com/?font=Cinzel&size=25&duration=1&pause=0&color=638EBD&center=false&vCenter=true&repeat=false&width=600&height=42&lines=Logs+and+support&letterSpacing=0.5px&weight=700)

- Run `/o3d diag` and include the log when [reporting a problem](https://github.com/SQLCommit/Occlude3d/issues).
- **Files:** `/ashita/logs/occlude3d/<Name>_<id>/occlude3d.log`
- Before login, logs go to `/ashita/logs/occlude3d/` and move into the character's log after login. Each log retains its newest 1 MB.
